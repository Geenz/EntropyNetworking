# Networking Features

EntropyNetworking provides a comprehensive suite of features for building connected applications.

## Core Features

*   **[Entity Replication](./Replication.md)**: Synchronize ECS entities and components between peers.
*   **[Component Schemas](./Schemas.md)**: Define, register, and version data structures for cross-application compatibility.
*   **[Assets](./Assets.md)**: Upload, fetch, and resolve content (textures, shaders, meshes) across the network.
*   **[HTTP Client](./HTTP.md)**: High-performance, asynchronous HTTP/1.1 and HTTP/2 client.

## Integration

These features are integrated into the `NetworkSession` and are available to any application using the Entropy framework.
